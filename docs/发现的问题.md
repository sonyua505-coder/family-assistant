## 问题 1: 插件层注释错误 - bind_person 工具描述误导

**位置**: `plugins/astrbot_star_homeassistant/main.py:L1920-1924`

**问题描述**:
`bind_person` 工具的注释写的是"把当前用户绑定到已有的账号（如家人把你拉进家庭）",这个描述完全错误。

**实际情况**:
- `bind_person` 是**身份合并**功能,会把多个平台身份绑定到同一个 person_id
- 加入家庭应该使用 `join_account` 工具,而不是 `bind_person`
- 两者完全不同:
  - `bind_person`: 多个 openid → 同一个 person_id (身份合并)
  - `join_account`: person 成为 account_members (加入家庭账本)

**影响**:
- 会误导 LLM 和用户,可能误用 `bind_person` 来"加入家庭"
- 导致身份被错误合并

**建议修复**:
修改注释为: "把当前平台身份绑定到已有的 person (用于合并多平台身份,如 QQ 和微信属于同一个人)"

## 问题 2: 缺少查询 person_id 的方法

**问题描述**:
插件层没有提供直接查询自己或他人 person_id 的方法。

**具体情况**:

1. **`get_my_identity` 工具没有返回 person.id**
   - 位置: `plugins/astrbot_star_homeassistant/main.py:L316-326`
   - 返回格式: `"已登记：{name}。可用账本：{acc}"`
   - 缺失: person.id
   
2. **需要 person_id 的工具无法使用**:
   - `bind_person(person_id)`: 需要别人的 person_id
   - `unbind_identity(person_id, platform, openid)`: 需要自己的 person_id

3. **后端 API 其实返回了 person.id**
   - 位置: `src/modules/system/routes.ts:L89-106`
   - 返回数据包含 `person.id`
   - 但插件层没有提取和展示

**影响**:
- 用户无法知道自己的 person_id
- 无法使用 `unbind_identity` 工具
- 无法正确使用 `bind_person` 工具

**建议修复**:
1. 修改 `get_my_identity` 工具的返回,包含 person.id
2. 或者修改 `unbind_identity` 不需要 person_id 参数 (后端可从身份注入获取)

## 问题 3: join_account 只支持 account_id,不支持账本名称

**位置**: 
- 插件层: `plugins/astrbot_star_homeassistant/main.py:L1933-1944`
- 后端路由: `src/modules/system/routes.ts:L260-274`
- 后端支持: `src/modules/system/accounts.ts:L130-144` (resolveAccountRef - **未使用**)

**问题描述**:
- 后端已有 `resolveAccountRef` 函数支持用账本名称解析账户 (支持数字 ID 和字符串名称)
- 但 `join_account` 路由**没有使用** `resolveAccountRef`，只接受数字 `account_id`
- 插件层 `join_account` 也只接受 `account_id: int`
- 用户需要知道数字形式的 account_id,不够友好

**注意**: `resolveAccountRef` 是一个**死代码**，写好了但没被调用

**建议修复**:
1. 修改 `join_account` 路由使用 `resolveAccountRef` 解析账户引用
2. 修改插件层 `join_account` 支持 `account_ref: int | string`

## 问题 4: 缺少注销/转移身份功能 - 已绑定后无法切换 person

**位置**: `src/modules/system/routes.ts:L150-153`

**问题描述**:
`bind_person` 要求当前身份未绑定 (`id.personId !== null` 时报错)，导致以下死锁场景：

1. 用户 A 用 QQ 创建了 person (person_id=1)
2. 后来发现另一个平台已有 person (person_id=2)，想绑定
3. 调用 `bind_person(person_id=2)` → 报错 `IDENTITY_ALREADY_BOUND`
4. 想先解绑 → `unbind_identity` 不允许解绑最后一个身份 (`CANNOT_UNBIND_LAST`)

**结果**: 用户一旦创建了 person，就无法切换到另一个 person，除非：
- 直接操作数据库删除
- 或者等待系统管理员介入

**缺少的功能** (三选一):
1. **注销/删除 person**: 删除整个 person 及其所有身份，释放身份
2. **转移身份**: 把当前身份从一个 person 转移到另一个 person
3. **合并 person**: 把 person A 的所有身份转移到 person B，然后删除 person A

**建议修复**:
增加 `delete_person` 或 `transfer_identity` 工具，让用户可以重新选择绑定目标
